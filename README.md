# Student Assistant Agent

An Agentic AI-based Student Assistant built using **Python, LangChain, and Groq**.

## Features

- Calculator for basic mathematical operations
- Student department information
- Student attendance information
- Answers general questions using AI
- Automatically selects the appropriate tool based on the user's question

## Technologies

- Python
- LangChain
- Groq
- Python-dotenv

## Example

```text
Calculate 250 * 15 / 100 → 37.5

What department does Arun belong to? → Arun is from the CSE department.

What is Priya's attendance? → Priya's attendance is 91%.
```

## How to Run

```bash
pip install -r requirements.txt
python main.py
```
